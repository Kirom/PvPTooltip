# PvP Tooltip - Enhanced Player Information

**Instantly see comprehensive PvP information for any player you encounter in World of Warcraft!**

PvP Tooltip is a lightweight addon that enhances your gameplay by displaying detailed PvP statistics directly in player tooltips. Whether you're evaluating potential teammates, assessing opponents, or simply curious about other players' PvP experience, this addon provides all the information you need at a glance — no clicks, no website, no setup.

> **🆕 New: four tooltip layouts!** Pick **Panel**, **Compact**, **Sections** or **Classic** in `/pvpt` → **Tooltip layout** and watch the live preview change as you choose.

## 🖼️ Choose Your Layout

### Panel (default)

![Panel layout](https://raw.githubusercontent.com/Kirom/PvPTooltip/master/assets/layouts/panel.png)

A clean table with column headers and a **rating bar** for every bracket. The fill shows the current rating and the tick marks the personal best, so you can see at a glance how close a player is to their peak.

### Compact

![Compact layout](https://raw.githubusercontent.com/Kirom/PvPTooltip/master/assets/layouts/compact.png)

One line per bracket with aligned **Current / Best / Played / Win%** columns. Everything you need in the fewest lines.

### Sections

![Sections layout](https://raw.githubusercontent.com/Kirom/PvPTooltip/master/assets/layouts/sections.png)

Current rating, personal best and games played in separate, clearly labelled sections. Easy to scan from top to bottom.

### Classic

![Classic layout](https://raw.githubusercontent.com/Kirom/PvPTooltip/master/assets/layouts/classic.png)

The original PvP Tooltip look, kept for everyone who loves it.

Every layout shows the same data and follows the same settings, so you can switch any time.

## ✨ Key Features

### 🎯 **Comprehensive PvP Data Display**
- **Current Season Ratings** for all competitive brackets (2v2, 3v3, Solo Shuffle, RBG, Blitz)
- **Personal Best Ratings** showing all-time peak performance per bracket
- **Season Statistics** including games played and win rate
- **Per-spec breakdown** for Solo Shuffle and Blitz with spec icons; when the hovered player's active spec is known, the other specs are dimmed
- **Color-coded ratings** for instant skill assessment

### 🌍 **Multi-Region, Frequently Refreshed**
- Region databases refreshed frequently from current ranked data
- Automatic region detection and appropriate data source selection
- Cross-realm and cross-faction player lookup

### 🎨 **Clean, Modern Design**
- **Four layouts**: Panel with rating bars, Compact table, Sections, or the Classic look
- **Color coding**: White (0-1799), Green (1800-2099), Blue (2100-2399), Purple (2400+)
- **Win rate indicators**: Red (≤50%), Green (>50%)
- **Minimal performance impact**, no measurable overhead

### ⚙️ **In-Game Settings Panel**
- Open with `/pvpt` or `Esc → Options → AddOns → PvPTooltip`
- **Live tooltip preview** updates as you change options
- **Pick your tooltip layout**: Panel, Compact, Sections or Classic
- Toggle columns, brackets and a show-on-modifier key (Shift/Ctrl/Alt)
- Choose all specs vs only the hovered spec; hide brackets with no games

### 🔧 **Zero Configuration Required**
- **Install and play** — sensible defaults out of the box
- **Automatic integration** with existing tooltip systems
- **Compatible** with popular UI addons and frameworks

## 📊 What You'll See

Hovering any player adds a PvP block to the tooltip with this data for each enabled bracket:

- **Current** — current-season rating, color-coded by skill level
- **Best** — all-time personal-best rating
- **Played** — games played this season
- **Win%** — win rate this season

## 🎮 Where It Works

PvP Tooltip enhances tooltips in all major game contexts:
- **World exploration** — hovering over players in the open world
- **Group content** — party and raid member information
- **Group Finder** — both when searching for groups and reviewing applicants
- **Social interactions** — guild, friends and other players
- **Battlegrounds & arenas**
- **Total RP 3** — shown at the bottom of TRP3 profile tooltips (can be turned off)

## 🔄 Installation & Updates

1. Install like any WoW addon (CurseForge, Wago, WowUp, or manual)
2. Restart your game or `/reload`
3. **Keep it updated** (enable auto-update) for the freshest data
4. Enjoy enhanced player tooltips immediately!

## 🔒 Privacy

PvP Tooltip never connects to the internet. If you use the Wago App with analytics on, it reports which tooltip layout you use (and any PvP Tooltip errors) through Wago Analytics, so we know which layouts are worth improving. You can opt out in the Wago App settings.
